# Pet Universe v97

Powrót do układu v95. Badge mają ciemne dopasowane tło i gradientowe napisy Nunito Black. Oznaczenia stoją obok siebie i zawijają się dopiero przy braku miejsca. Exclusive pozostaje rarity; 1M Event jest osobnym oznaczeniem. Universe Shard ma rarity Exclusive. Obramowania kart i ruchomy refleks mają szerokość 1 px.

Rozpakuj folder Pet Sim Universe na Pulpit. Zachowaj własne nowsze public/data/prices.js oraz prywatną konfigurację Discorda. Uruchom Upload-GitHub.ps1 z tego folderu.

Ceny edytujesz w public/data/prices.js. Po zmianach CSS uruchom npm run build. Pakiet zawiera już zbudowane pliki.
