# Pet Universe Values v90

Badge: wspolny styl Legendary, lzejszy tekst i niebieski 1M Event.

Rozpakuj i podmien pliki w istniejacym folderze Pet Sim Universe. Zachowaj lokalny folder .cloudflare.
Po podmianie uruchom PowerShell w folderze projektu:

powershell -NoProfile -ExecutionPolicy Bypass -File .\Upgrade-Discord.ps1

Upgrade wdraza monitor i testuje Discord; nie wysyla plikow strony na GitHub. Strone wyslij dotychczasowym Upload-GitHub.ps1.
Ceny edytuj w public/data/prices.js. ZIP zawiera stan pobrany z GitHub podczas przygotowania — zachowaj nowsze lokalne zmiany cen.
