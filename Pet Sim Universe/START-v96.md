# Pet Universe v96

Pełny projekt: rarity bez tła, gradientowe napisy Nunito Black, animowane obramowanie kart i mniejszy, uporządkowany układ telefonu. Exclusive pozostaje rarity, 1M Event jest dodatkowym oznaczeniem.

Rozpakuj folder Pet Sim Universe na Pulpit. Zachowaj własne nowsze public/data/prices.js oraz prywatną konfigurację Discorda. Uruchom Upload-GitHub.ps1, aby wysłać projekt do repozytorium.

Ceny: public/data/prices.js. Zmiany wyglądu: końcowa sekcja public/v89.css. Po własnych zmianach wyglądu uruchom npm run build.

Przycisk animacji zatrzymuje również obramowania. Na telefonie ruch obramowań zatrzymuje się podczas przewijania; ustawienie ograniczenia ruchu jest respektowane.
